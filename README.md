Как пользоваться этим говном:
- Самая последние изменения находятся на сцене 4
- При запуске появляются 4 кнопки, каждая отвечает за постановку комнаты своего размера (View отвечающая за кнопки прикреплено к UI)
- Первую комнату можно ставить на любую зелёную клетку (смотри на Scene). На краные ставить нельзя это Margin. (GridController лежит в Terrain)

- На пробел можно вращать комнату
- Все проверки при установки комнаты осуществляются через GridController и утилки связанные с ним.
